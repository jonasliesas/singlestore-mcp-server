---
name: singlestore-notebook
description: "Open a SingleStore notebook (SQL + Python on a Jupyter kernel)."
argument-hint: "[database] [notebook file]"
---

Open the SingleStore Workspace on the notebook view with the singlestore `sql_editor` tool (view "notebook"). Arguments: "$ARGUMENTS" — a database name (case-sensitive) if given. If a .ipynb file is named, open it with the singlestore `notebook` tool instead (name = that file). Post the browser link under the app.
