argument-hint: "[database] [view: sql|notebook|schema|pipelines|cluster]"

Open the SingleStore Workspace with the singlestore `sql_editor` tool. Arguments: "$ARGUMENTS" — the first word, if any, is the database (case-sensitive), and a word sql, notebook, schema, pipelines or cluster is the view to open (default sql). Post the browser link from the result as a clickable link under the app.
